Pregunta 1

Describe el archivo package.json.

Respuesta: Los archivos tipo JavaScript Object Notation o .JSON son archivos diseñados para el almacenamiento y transimisón de metadatos entre programas. A grandes rasgos contienen la configuracion fundamental del programa. En este caso contienen las librerías y la configuracion de Node y el proyecto de NPM que tienes. Ademas permite definir scripts personalizados para iniciar, probar o compilar el proyecto. Es super util pues por ejemplo si necesitas una versión específica de una librería, para evitar errores de compatibilidad, puedes cambiar el número de versión directamente en el package.json.

Referenicas: GeeksforGeeks. (2024, July 24). What is package.json in Node.js ? GeeksforGeeks. https://www.geeksforgeeks.org/node-js/what-is-package-json-in-node-js/

Lab 6 Programación orientada a Eventos preguntas

Pregunta 1

pregunta:¿Por qué es una buena práctica usar JavaScript para checar que sean válidos los inputs de las formas antes de enviar los datos al servidor?

Respuesta: Esta practica consiste en revisar y validar a traves de Java Script (utilizando el evento Submit) los inputs de un usuario. Esto es una buena practica pues hace posible detectar errores en tipos o valores en tiempo real (del lado del cliente). Al reducir la probabilidad de datos incompatbles al servidor, disminuimos la cantidad de requests que le le haríamos al servidor para corregir errores. De esta forma le quitamos peso de trabajo al Servidor haciendo de la experiencia del usuario una mas fluida.

Referenicas: Gautam, R. (2024, March 27). JavaScript validation : An overview of client side validation. https://learnsic.com/blog/javascript-validation-an-overview-of-client-side-validation

Pregunta 2

pregunta:¿Cómo puedes saltarte la seguridad de validaciones hechas con JavaScript?

Respuesta: Recordamos que a final de cuentas esta validación se hace en JavaScript al cual el usuario tiene facil accesos como cliente. El script de JS puede ser facilmente deshabilitado o midificado para saltarse esta validación y mandar el formulario sin verificación. No es algo tan dificil de hacer por lo que se debe de tener contramedidas a esta situación. La Seguridad central es y debe estar en el Servidor el cual debe de verificar y limpiar todos los datos.

Referencias: MSEdgeTeam. (n.d.). Deshabilitar JavaScript - Microsoft Edge Developer documentation. Microsoft Learn. https://learn.microsoft.com/es-es/microsoft-edge/devtools/javascript/disable

Pregunta 2

Si te puedes saltar la seguridad de las validaciones de JavaScript, entonces ¿por qué la primera pregunta dice que es una buena práctica?

Respuesta: La validación de datos por JavaScript juega el rol de mejora de experiencia del usuario al aligerarle carga de procesamiento al Servidor y funge como una primera fina defensa contra datos incorrectos. No obstante su rol no es de seguridad ni protección. Estas actividades esenciales se hacen obligatoriamente en el Servidor. Entonces aunque esta practica ayuda mucho en la experiencia de usuario, no juega el rol de seguridad y obligatoriamente debe de haber mediades de protección en el servidor.
